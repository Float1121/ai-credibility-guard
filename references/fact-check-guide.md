# 水落辨真 — 事实核查参考手册

本文档定义了Step 3（事实核查）的搜索验证策略、核查结果判定标准和常见陷阱。

## 一、搜索验证策略

### 1.1 分场景搜索策略

| 场景类型 | 搜索优先源 | 搜索关键词构造规则 | 示例 |
|----------|------------|-------------------|------|
| R1 健康安全 | 权威医疗机构官网、CDC、WHO | "物种名 + 毒性/食用安全 + 官方" | "见手青 毒性 食用安全 CDC" |
| R2 用药指导 | 国家药监局、药品说明书、UpToDate | "药物名 + 交互/禁忌 + 说明书" | "布洛芬 阿司匹林 药物交互 说明书" |
| R3 法律建议 | 法律法规数据库、12348官网 | "关键词 + 法律法规/司法解释" | "租房押金不退 法律规定" |
| R4 金融决策 | 证监会、银保监会、央行官网 | "平台名 + 牌照/资质 + 监管" | "XX理财平台 金融牌照 证监会" |
| R5 身份核验 | 反诈中心、官方渠道 | "诈骗类型 + 识别方法 + 官方" | "AI换脸诈骗 识别方法 反诈中心" |
| R6 信息真伪 | 辟谣平台、权威媒体 | "事件关键词 + 辟谣/核实/真假" | "XX事件 辟谣 核实" |
| R7 情感操控 | 辟谣平台、民政部 | "募捐/事件名 + 核实/真假" | "XX求助 核实真伪" |
| R8 隐性营销 | 企查查、广告法 | "品牌/博主名 + 广告/代言/合作" | "XX博主 XX品牌 合作" |
| R9 学术诚信 | Google Scholar、CNKI | "论文标题/作者 + 原文/验证" | "XX论文 原文 验证" |
| R10 食品安全 | 食品安全标准、风险评估中心 | "食品名 + 安全标准/保质期" | "XX食品 保质期 GB标准" |

## 二、核查结果判定

### 2.1 三级判定标准

| 判定 | 条件 | 对应动作 |
|------|------|----------|
| ✅ 已验证 | 找到2个以上权威来源佐证AI回答 | 降级提示或仅标注 |
| ⚠️ 存疑 | 未找到权威佐证，或存在矛盾信息 | 维持风险提示 + 推荐验证 |
| ❌ 矛盾 | 找到权威来源与AI回答直接矛盾 | 升级为强风险提示 + 纠正信息 |

### 2.2 常见"看起来对但实际错"的模式

| 模式 | 描述 | 示例 |
|------|------|------|
| 半真半假 | 事实框架正确但关键细节错误 | "布洛芬可以退烧"✅ 但"布洛芬和阿司匹林可以一起吃"❌ |
| 过时信息 | 曾经正确但标准已更新 | 旧版食品安全标准 vs 新版GB标准 |
| 遗漏关键条件 | 正确但不完整 | "XX药物成人可用"但遗漏了"孕妇禁用" |
| 语境错位 | 在其他语境正确但此处不适用 | 兽药信息被用于人药咨询 |
| 绝对化表述 | 相对正确的结论被AI表述为绝对 | "肯定没问题" vs 实际存在个体差异 |

## 三、常见陷阱与对策

| 陷阱 | 表现 | 对策 |
|------|------|------|
| AI自信地编造数据 | 给出精确到小数点的数据但无法溯源 | 所有数据必须搜索验证，无来源=不可信 |
| AI引用不存在的来源 | 编造论文标题、机构名称 | 搜索论文标题/机构名，确认是否存在 |
| AI混淆相似概念 | 把A药物的说明套用到B药物 | 核查时必须精确匹配药物通用名 |
| AI给出"免责声明"但仍误导 | 说"我不是医生"后继续给出具体建议 | 免责声明不降低风险，仍需提示 |
| 用户反复追问导致AI妥协 | 用户施压后AI改变立场 | 追踪多轮对话立场变化，标注"立场偏移" |
