# 水落辨真 — AI交互可信度自动守护Skill

## 风险场景分类与判定规则

本文档定义了水落辨真Skill识别的所有风险场景类型、判定规则、可信度评估维度和推荐渠道映射。

---

## 一、风险场景分类总览

| 编号 | 场景类型 | 风险等级 | 典型触发词/意图 | 核心风险 |
|------|----------|----------|----------------|----------|
| R1 | 健康安全 | 🔴 高 | 蘑菇能吃吗、这个偏方靠谱吗、被蛇咬了怎么办 | AI误判→身体伤害甚至死亡 |
| R2 | 用药指导 | 🔴 高 | 这两种药能一起吃吗、孕期可以吃XX吗、给孩子用XX剂量 | AI瞎指导→药物不良反应 |
| R3 | 法律建议 | 🟡 中 | 我能起诉吗、这算犯罪吗、合同这样签合法吗 | AI给法律意见→误导决策→权益受损 |
| R4 | 金融决策 | 🔴 高 | 这只基金值得买吗、这个理财安全吗、推荐个股票 | AI荐股/理财→财产损失 |
| R5 | 身份核验 | 🔴 高 | 视频里的人真的是XX吗、这个客服是真的吗、帮我看看这个电话是不是诈骗 | AI换脸/声克隆→诈骗 |
| R6 | 信息真伪 | 🟡 中 | 这张图是真的吗、这个新闻靠谱吗、这段视频是AI生成的吗 | 深度伪造→被误导/被骗 |
| R7 | 情感操控 | 🟡 中 | 这个让我感动的故事是真的吗、帮我看这个募捐靠不靠谱 | 编造情感内容→被操控/被骗捐 |
| R8 | 隐性营销 | 🟡 中 | 这个推荐是广告吗、博主说好好用是真心话吗 | 软广伪装成真实体验→冲动消费 |
| R9 | 学术诚信 | 🟡 中 | 这个数据来源靠谱吗、这篇论文结论可信吗 | AI编造引用/数据→学术不端 |
| R10 | 食品安全 | 🔴 高 | 过期XX还能吃吗、这个食品添加剂安全吗、冰箱放了X天的XX | AI误判→食物中毒 |

## 二、场景判定规则（用于Step 1场景识别）

### 2.1 关键词触发规则

```
IF 用户消息包含以下模式 → 标记对应风险场景：

R1 健康安全：
  - 物种识别意图："[这个/那种][蘑菇/菌/野菜/草药/植物/动物/蛇/虫]能[吃/碰/用]吗"
  - 偏方验证意图："[偏方/土方/老方子/秘方]靠谱/有效/可信吗"
  - 急救咨询意图："[被咬/中毒/过敏/烫伤]怎么办/怎么处理"
  - 疾病自诊意图："[这个症状/这种情况]是[什么病/严重吗/要不要去医院]"

R2 用药指导：
  - 药物交互意图："[XX药][能/可以][跟/和][YY药][一起吃/同时用]吗"
  - 特殊人群用药："[孕妇/哺乳期/儿童/老人/肝肾功能不好]能[吃/用]XX吗"
  - 剂量咨询："[XX药][吃/用][多少/几片/几ml/什么剂量]"
  - 停药判断："能[停/不吃][XX药]吗"

R3 法律建议：
  - 诉讼判断："[能/可以]起诉吗、[有/没有]法律依据"
  - 犯罪认定："这算[犯罪/违法/诈骗]吗"
  - 合同审查："合同[这样签/这条/这个条款]合法吗"
  - 维权路径："我[该/能]怎么办、[怎么/如何]维权"

R4 金融决策：
  - 投资建议："[推荐/买不买/值不值得][股票/基金/理财/币/项目]"
  - 收益承诺："[保证/稳赚/包赚/年化XX%]是真的吗"
  - 平台安全："[这个平台/APP/网站][靠谱/安全/正规]吗"
  - 贷款咨询："[贷款/网贷/信用卡]靠谱吗、利息高不高"

R5 身份核验：
  - 换脸嫌疑："视频里的人真的是XX吗"
  - 诈骗识别："这个[客服/银行/公安/领导]是真的吗"
  - 语音真伪："这个电话/语音是本人吗"

R6 信息真伪：
  - AI生成检测："[这个/这张/这段][图/视频/音频][是真的/是AI生成的]吗"
  - 新闻验证："[这个新闻/消息/传言]是真的吗"
  - 来源核实："这个[数据/统计/报告]从哪来的"

R7 情感操控：
  - 募捐验证："[这个募捐/众筹/求助]是真的吗"
  - 情感真实性："这个故事/经历是真的吗、有没有被设计"
  - 悲情营销："让人[心疼/感动/愤怒]的内容是真的吗"

R8 隐性营销：
  - 广告识别："[这个推荐/安利/种草]是广告吗"
  - 体验真实性："[博主/达人/用户]说的[真心话/真实体验]吗"
  - 利益关联："[推荐/好评]有没有[利益/佣金/合作]"

R9 学术诚信：
  - 引用验证："[这个引用/数据/统计]来源靠谱吗"
  - 结论可信度："[这篇论文/研究]结论可信吗"
  - 数据真实性："[这个数据/图表]是真实的吗"

R10 食品安全：
  - 保质期判断："过期/放了X天的XX还能吃吗"
  - 添加剂安全："这个[添加剂/防腐剂/色素]安全吗"
  - 储存安全："XX[放冰箱/常温/微波炉加热]后还能吃吗"
```

### 2.2 上下文推断规则

当关键词未直接命中，但上下文暗示高风险时，同样触发：

```
IF 用户对话中出现以下上下文模式 → 补充标记风险场景：

- 用户提到"老人/爸妈/孩子"在用AI获取建议 → 额外标记"弱势群体"标签，提升风险等级
- 用户表达紧急情绪（"急""马上""现在就要"） → 提升风险等级一级
- 用户提到已经执行了AI建议（"我按你说的吃了/买了/签了"） → 触发"事后补救"模式
- 多轮对话中AI建议逐步升级风险（从"试试"到"一定要"） → 触发"建议升级"警告
```

## 三、可信度评估维度（用于Step 2）

### 3.1 AI回答可信度评分框架

对AI生成的回答，从以下5个维度评估可信度：

| 维度 | 权重 | 评估标准 | 低可信信号 | 高可信信号 |
|------|------|----------|------------|------------|
| 领域专业度 | 30% | AI在此领域的专业程度 | 模糊措辞、回避细节、自相矛盾 | 引用具体数据、标准、法规 |
| 事实可验证性 | 25% | 回答中的事实是否可被验证 | 无法搜索验证的数据/引用 | 可查证的数据来源、链接 |
| 风险后果严重度 | 25% | 如果AI说错，后果有多严重 | 涉及生命/财产/法律 | 日常生活建议、低风险查询 |
| 确定性表达 | 10% | AI的措辞有多确定 | "一定是""绝对""肯定" | "可能""建议""请咨询专业人士" |
| 一致性 | 10% | 与已知权威信息的一致性 | 与常识/权威指南矛盾 | 与权威来源一致 |

### 3.2 可信度等级映射

| 综合得分 | 等级 | 颜色标识 | 处理策略 |
|----------|------|----------|----------|
| 0-30 | 极低可信 | 🔴 | 必须插入强风险提示 + 推荐渠道 |
| 31-50 | 低可信 | 🟠 | 插入风险提示 + 建议验证 |
| 51-70 | 中等可信 | 🟡 | 插入轻提示 + 提供验证选项 |
| 71-85 | 较高可信 | 🟢 | 仅标注场景类型，不打断对话 |
| 86-100 | 高可信 | ⚪ | 静默放行 |

## 七、特殊规则

### 7.1 弱势群体加成

当识别到用户可能是为老人/儿童/孕妇咨询时，所有风险等级自动提升一级（🟡→🟠，🟠→🔴），因为：
- 老年人对AI内容辨别能力更弱
- 儿童身体对错误建议的承受力更低
- 孕期用药错误可能影响胎儿

### 7.2 紧急场景优先级

当用户表达紧急情绪时，优先显示最关键的1-2条行动建议（如"立即拨打120"），而非完整的风险分析卡片。

### 7.3 误触发保护

以下情况**不应触发**风险提示：
- 用户明确表示在写作/创作（"我在写小说，角色遇到..."）
- 用户明确表示在学习/考试（"考试问的是..."）
- 用户主动要求评估风险（"帮我看看这个有没有风险"）——此时直接执行评估而非再插提示
- 闲聊/娱乐性质的问题（"假如我吃了毒蘑菇会怎样"中的"假如"是假设语气）
